# Security policy

Fast OFM is a research prototype, not a medical device. Do not use it for
diagnosis or rely on it as a safety controller.

Report vulnerabilities privately through the repository's GitHub Security
Advisories page. Do not put credentials, private network details, patient data,
or unpublished specimen images in an issue. Include the affected release tag,
feature ID, impact, and a minimal reproduction that contains no sensitive data.

The current maintained line is `v0.2.0-prototype.*`. Security fixes may change
prototype interfaces when fail-closed behaviour requires it.
